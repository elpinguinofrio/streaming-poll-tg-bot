# Implementation Plan: Topic Suggestions Bot

**Branch**: `001-topic-suggestions-bot` | **Date**: 2026-09-16 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/001-topic-suggestions-bot/spec.md`

## Summary

A single-process Telegram bot (long polling) that stores text and voice topic suggestions from
private chats, transcribes voice via Groq whisper-large-v3, acknowledges with a 👍 reaction only
after persistence, and gives the configured author a `/summary` digest generated by a Groq LLM.

## Technical Context

**Language/Version**: Python 3.13 (uv-managed; aiogram requires <3.15)

**Primary Dependencies**: aiogram 3.31, groq 1.7, aiosqlite 0.22, pydantic-settings 2.15

**Storage**: SQLite file `data/suggestions.db` (path configurable)

**Testing**: pytest 9 + pytest-asyncio 1.4; Telegram and Groq mocked at adapter boundary

**Target Platform**: macOS/Linux host running during streams

**Project Type**: single long-running bot process

**Performance Goals**: 👍 on text ≤3 s, on 60 s voice ≤10 s; summary of 500 items ≤30 s

**Constraints**: secrets never logged/printed; DM-only; Russian user-facing replies

**Scale/Scope**: one author, hundreds of viewers per stream, ≤ a few thousand suggestions

workflow data, so handlers are unit-testable with fakes.
